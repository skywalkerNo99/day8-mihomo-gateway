# macOS 单 App 收敛与本机迁移

macOS 只支持 Day8 Gateway 自有系统 TUN、用户分流核心和管理 App。Linux 原生与容器接口保持原状。已有 Clash 兼容安装只允许迁移；故障恢复直接恢复原 Clash 配置并停止网关，不重新启用兼容服务。

## 设计

- 用户登录服务始终运行 `single_app.routing`、物理网卡 Muon 出站、加密域名规则、日志与住宅编辑，不再根据标记文件选择兼容运行方式。
- 新安装只需要 vault、原生核心及管理员授权，不要求安装 Clash 或提供其 profile/controller。后台先在回环核验，经固定系统服务接管 TUN 后再验收。
- 迁移保存原代理状态；新用户服务及回环出口通过后才安装 PF、退出原代理并启动 TUN。失败时停止网关并恢复迁移前的原代理，不依赖兼容服务。
- CLI 和文档只给出单 App 安装、迁移、检查、升级、回退和卸载。桌面核验始终检查系统 TUN。
- 真实配置只在内存、加密 vault 或系统服务已有的本机 handoff 机制中传递；密码仅由用户在本机终端隐藏输入。
